# 言い換え辞典自動投稿システム

『社会人の言い換え辞典』の動画を、毎朝自動で「台本作成 → 音声 → 動画合成 →
YouTube投稿 → コメント投稿 → 成績記録（テーマ別）→ ルール改善（PDCA）」まで
行う仕組みです。実行基盤は GitHub Actions、費用はすべて無料枠内です。

『15秒のひとことポスト』のシステムを複製・改修した、2シリーズ目専用の
システムです。投稿先は新しく作る専用チャンネルで、ひとことポスト側の
リポジトリ・スプレッドシート・Secrets とは完全に分かれています。

**設定方法は [SETUP_GUIDE.md](SETUP_GUIDE.md) を見てください。**
コマンド操作は不要で、ブラウザのクリックとコピペだけで設定できます。

手動で今すぐ1本作りたいときは、リポジトリの「Actions」タブから
「iikae-jiten-daily」を選び、「Run workflow」を押してください。
